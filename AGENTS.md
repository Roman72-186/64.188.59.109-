# payment-proxy — платёжная прокладка

Принимает оплату у провайдера (Т-Банк эквайринг, Долями Partner API, T-Bank Credit
Broker), фискализирует чек через CloudKassir и после подтверждённого платежа выдаёт
доступ: назначает тег в shalamov.io либо зовёт callback бота.

**Категория:** B (свой продукт) — код владельца, обслуживает и свою кассу, и клиентские
интеграции.

## Единый мозг проекта

- Codex и Claude Code равноправны: любой продолжает работу после другого.
- Handoff между сессиями и агентами — **`session-handoffs/current.md`**. `NEXT-CHAT.md`
  остался архивом истории чатов и источником правды больше не является (см. ниже).
- `Сохранить сессию` → протокол `C:\Users\User\.agents\skills\save-session\SKILL.md`,
  результат перезаписывает `session-handoffs/current.md`.
- `Прочитай сохранённую сессию` → сначала `session-handoffs/current.md`, потом `CLAUDE.md`.
- Найденное правило фиксировать в файлах, а не только в диалоге. Если оно шире проекта —
  в `../../principles/` или `../../feedback/`.
- Всё писать по-русски: ответы, комментарии, коммиты, документацию, handoff. Технические
  имена кода (`payment_method`, `atomic_capture`, `tbank-proxy`) — как есть.

## Границы работы

- **У проекта свой git** — `github.com/Roman72-186/64.188.59.109-`. Коммитить **изнутри
  этой папки**, не из корня `Project`. Корневой репозиторий папку игнорирует.
- **Прод крутится с ветки `fix/shalamo-401-tag-reconciler`, не с `main`.** Не переключать
  и не мержить без явной просьбы владельца.
- **`git add -A` внутри папки опасен.** Здесь лежат боевые ключи и выгрузки с персданными
  клиентов; remote публичный. Стейджить по путям, `.gitignore` проверять до коммита.
- Соседние проекты workspace не трогать: `bot/` рядом — отдельная зона.

## Что нельзя делать без подтверждения владельца

- **Перезаписывать `config.yaml`, `.env`, `*.pem`, `*.key`, `payments.db`** — там боевые
  доступы, создаются вручную. Не печатать их значения в чат.
- **Мутирующие вызовы боевых API**: `commit` у Долями — это реальный захват денег;
  назначение тега в shalamov.io шлёт клиенту авторассылку. Инцидент 01.07.2026: тестовые
  прогоны назначили `paid_yes` двум реальным контактам.
- **Пробивать чек через CloudKassir** по боевым заказам ради проверки.
- Деплой на `72.56.8.174` и рестарт `tbank-proxy` — по [../../reference/deploy-runbook.md](../../reference/deploy-runbook.md).

## Два инстанса одного кода

Поведение задаётся только через `config.yaml`, код под конкретный проект не правится.
Поэтому один и тот же код обслуживает два разных развёртывания:

| Инстанс | Конфиг | Роль |
|---|---|---|
| Клиентский (Регина Габриелян, shalamov.io) | `config.yaml` | боевой прод на `72.56.8.174`, юнит `tbank-proxy`: Долями + Credit Broker + CloudKassir |
| Касса бота `@arhi_botov_bot` | `config.arhi-botov.yaml` | один способ `card`, порт 8090, shalamo-адаптер указывает не наружу, а на сам бот (`webhook_receiver`, порт 8091) |

Оба файла в `.gitignore`. Правя код, держать в голове оба: ломается поведение сразу двух
развёртываний.

> **Где физически крутится второй инстанс — не проверено.** Комментарий в
> `config.arhi-botov.yaml` называет VPS бота `72.56.77.253`, а `../CLAUDE.md` говорит, что
> актуальная прокладка для бота — `tbank-proxy` на `72.56.8.174`. Возможно, отдельного
> развёртывания уже нет и файл остался от прежней схемы. Перед работой с кассой бота
> уточнить у владельца, не считать таблицу подтверждением живого сервиса.

Роль прокладки в связке с ботом — [../CLAUDE.md](../CLAUDE.md) и
[../INTEGRATION.md](../INTEGRATION.md).

## Ловушки проекта

Полный список — в [CLAUDE.md](CLAUDE.md). Самое дорогое, если забыть:

- **Суммы в конфиге и БД — в копейках**, у Долями и Credit Broker API принимает рубли
  (конвертация через `Decimal`).
- **Тег назначается синхронно**, при сбое shalamo webhook отдаёт `503` — банк повторит.
  Поэтому `shalamo.timeout_seconds * 2` обязано влезать в таймаут webhook (~10 с).
- **mTLS-сертификат Долями нужен на каждый запрос**, пути в конфиге абсолютные.
- **`canceled` — не отказ.** Тег «оплата не прошла» ставится только на `rejected`, иначе
  спам по тем, кто открыл форму и ушёл.
