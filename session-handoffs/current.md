`uv pip install --python venv -r requirements.txt`). Системный Python здесь 3.14, под него

  не понадобился: он обходил падение сборщика на кириллице в старом пути, а в
  `ai-clone/bot/payment-proxy/` кириллицы нет.
- `test_flow.py` сначала **упал** — и это не следствие переноса. Коммит `8af9577`
  (09.06.2026) «amount обязателен в /init-payment, из конфига не берётся» изменил контракт,
  а скрипт последний раз трогали в `63cf1dc` (03.06.2026) и под новый контракт не обновили.
  Он слал `/init-payment` без `amount` → «сумма не передана и не задана в config» → 3 из 12
  проверок падали, дальше `TypeError` на `order["tbank_payment_id"]` у None. Починено одной
  строкой: в payload добавлен `amount: 9900` (совпадает с `Amount` в webhook-payload ниже
  по скрипту и с `FakeTBank.state`). После правки — **все 12 проверок PASS**.
  README обещал «все PASS», так что скрипт был сломан почти два месяца незаметно.
- Вывод в консоль Windows идёт в мохибейке: логи в UTF-8, консоль в cp1251. На результат
  не влияет, для чтения ошибок запускать с `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`.

**На сервер ничего не заливалось**, поведение прокладки не трогалось: правки только в
