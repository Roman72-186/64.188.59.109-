# Инцидент 2026-07-02 — Долями: ссылка на оплату не выдалась (mTLS-сертификаты не перенесены при миграции)

## Кратко

Клиент запросил оплату Долями, но ссылка на оплату не пришла — `/init-payment`
завершился ошибкой создания заказа у Долями:

- order: `314_3011564_c7fe3f6b`
- contact_id: `3011564`
- payment method: `dolyami`
- amount: `1700000` (17 000 ₽)
- item: `Доступ в Сообщество Я ЕСТЬ`
- created_at: `2026-07-02T06:31:32+00:00`
- status: `failed`, pay_url: пусто
- last_error: `Долями create: None [Errno 2] No such file or directory`

Карта/СБП (эквайринг Т-Банка) при этом работали без сбоев.

## Причина

**При миграции со старого сервера `64.188.59.109` на новый `72.56.8.174` (01.07.2026)
не были перенесены файлы mTLS-сертификата Долями** — `2-certificate-2026-06-08-bnpl.pem`
и `2-private1.key`. Partner API Долями требует клиентский сертификат на каждый запрос
(`httpx cert=(crt, key)`); при отсутствии файлов httpx падает с `[Errno 2] No such file
or directory` ещё до сетевого вызова → `create` не выполняется → `pay_url` не выдаётся.

В `config.yaml` пути были заданы **относительными** (`cert_path: 2-certificate-...`),
что дополнительно маскировало проблему (зависимость от рабочей директории процесса).

## Исправление (02.07.2026)

1. Файлы сертификата и ключа скопированы из локального репозитория (лежат в корне
   проекта на Windows-машине) в `/opt/tbank_proxy/` на новом сервере.
2. Права: `chown www-data:www-data`, ключ `chmod 600`, сертификат `644`.
3. В `config.yaml` пути заменены на **абсолютные**:
   `cert_path: /opt/tbank_proxy/2-certificate-2026-06-08-bnpl.pem`,
   `key_path: /opt/tbank_proxy/2-private1.key`
   (бэкап: `config.yaml.bak-20260702-dolyame-certs`).
4. mTLS проверен с сервера: `curl --cert ... --key ... -u login:password
   https://partner.dolyame.ru/v1/orders/<тест>/info` → HTTP 404 («заказ не найден») —
   хендшейк и Basic-авторизация проходят.
5. `systemctl restart tbank-proxy`, `/health` → `ok`.

Клиенту достаточно повторно нажать кнопку оплаты Долями в боте — новая ссылка выдастся.

## Попутно найдено и исправлено

- **Поллер Credit Broker был выключен** на новом сервере: в блоке `tbank_credit`
  отсутствовал `poll_interval_seconds` (дефолт `0`). Поскольку `webhookURL` в `Create`
  не передаётся, опрос `GET /info` — единственный канал статуса кредитной заявки:
  без поллера тег после подписания кредита не назначился бы никогда. Включён опрос
  каждые 60с (бэкап: `config.yaml.bak-20260702-credit-poller`); первый цикл успешно
  опросил висящую заявку `installment_10` того же контакта (статус `new`).

## Уроки / что осталось

- Чек-лист миграции должен включать **файлы вне git** (сертификаты, `config.yaml`,
  `.env`, БД) — `.gitignore`-содержимое не переносится копированием репозитория.
- Пути к сертификатам в конфиге держать **абсолютными**.
- `shalamo.reconcile_interval_seconds` на сервере всё ещё `0` (реконсилятор
  «оплачено, но тег не назначен» выключен) — рекомендуется включить после
  инцидентов shalamo 500/403 от 01.07.
